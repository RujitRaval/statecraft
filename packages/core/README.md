# statecraft-ui-core

Browser-independent Statecraft contracts for configuration validation, deterministic matrix expansion and artifact paths, coverage calculations, and schema-v1 result/report parsing.

```ts
import { defineConfig, expandMatrix, parseReport } from "statecraft-ui-core";
```

Most users should install [`statecraft-ui`](https://www.npmjs.com/package/statecraft-ui). Use this package directly when building integrations around Statecraft's stable core contracts.

See the [core API documentation](https://github.com/RujitRaval/statecraft/blob/main/docs/engineering/CORE_API.md).
