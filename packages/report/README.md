# statecraft-ui-report

Deterministic transformation and self-contained offline HTML generation for validated Statecraft schema-v1 reports.

```ts
import { renderReportHtml, transformReport } from "statecraft-ui-report";
```

Most users should install [`statecraft-ui`](https://www.npmjs.com/package/statecraft-ui). Use this package directly when embedding Statecraft's report renderer in another local tool.

See the [report API documentation](https://github.com/RujitRaval/statecraft/blob/main/docs/engineering/REPORT_API.md).
