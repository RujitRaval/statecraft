# Contributing Plan

Provide reproducible setup, architecture overview, package ownership, test commands, and example-app workflow.

Contribution categories: core bugs, runner, report UX/accessibility, example scenarios, documentation, and future adapters only after an adapter API exists.

All behavior changes need tests. Public API changes need docs and schema compatibility consideration. New dependencies require justification.

Suggested labels: `good first issue`, `help wanted`, `bug`, `report-ui`, `runner`, `cli`, `docs`, `example`, `proposal`.
